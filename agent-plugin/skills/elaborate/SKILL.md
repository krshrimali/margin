# Elaborating on the board

The user wants more depth on one thing, not a new topic.

1. Find the target: the focus area, the circled or arrowed item, or the earlier card they point at. If it is your earlier card, build on it and don't repeat it.
2. If the target names a file, folder or codebase, read the relevant files first (you can read any directory) and ground the answer in what they actually contain.
3. Write the card in this order, plain text, up to about 350 words:
   - One line: the core idea restated more precisely than before.
   - HOW IT WORKS: 3 to 6 bullets on the mechanism, each a cause and its effect.
   - EXAMPLE: one concrete, specific example (real numbers, names or a short snippet).
   - EDGE CASES: 1 to 3 bullets on where it breaks, trade-offs or common mistakes.
   - NEXT: one line on what to explore after this.
4. Draw one visual that carries the extra depth, following the board drawing guide: a process or <diagram> for a mechanism, a comparison for a trade-off, an annotated example for code. Use a step-by-step walkthrough if the idea unfolds in stages.
5. Skip any section that would only be filler.
